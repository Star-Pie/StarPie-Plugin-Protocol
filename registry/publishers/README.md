# 发布者登记目录

此目录只保存发布者 JSON：

```text
github-<GitHub 数字用户 ID>.json
```

- 新手登记教程：[发布者注册](../../docs/getting-started/publisher-registration.md)
- 可复制模板：[publisher.example.json](../../templates/publisher.example.json)
- 完整注册表规则：[registry/README.md](../README.md)

MVP 仅支持 GitHub 个人用户和 `io.github.<login>` 命名空间。不要在此目录存放插件版本、二进制文件、私人邮箱或凭据。
